# Portfolio — Lương Tiến Dũng

Trang cá nhân giới thiệu dự án, thành tích lập trình thi đấu và CV.

**Xem trực tuyến:** https://luong-dung.github.io/portfolio/

## Chạy local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Đẩy lên `master` sẽ tự build và deploy lên GitHub Pages (`.github/workflows/deploy.yml`).

CV PDF nằm trong `public/cv/`.
